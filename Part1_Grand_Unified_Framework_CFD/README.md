# Supplementary Materials Guide for the Grand Unified Framework(H.U.G.G.E.R + TZT)

## Package contents

- `Grand_Unified_Framework_HUGGER_TZT_CFD_v1.X.X.pdf` : The definitive main manuscript establishing the Grand Unified Framework of H.U.G.G.E.R and the Topological Zero Tensor (TZT).
- `Supplementary_1_Analytical_Proofs` : Analytical derivations of topological bounds and enstrophy dissipation estimates for the integrated system (.pdf).
- `Supplementary_2_Formal_Verification_Lean4` : Mechanized formal verification code for conditional vorticity bounds and geometric rigidity in Lean 4 (.lean).
- `Supplementary_3_CAS_Python_Proofs` : Computer Algebra System (CAS) verification scripts for tensor identities and algebraic consistency (.py).
- `Supplementary_4_Numerical_Validation_DNS` : Benchmark data, official integrated solver, and visualization code demonstrating non-linear vortex suppression and dissipation dynamics (.csv, .py, .png).
